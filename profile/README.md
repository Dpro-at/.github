## Build with Girru

**One AI team. Shared context. Your control.**

Girru brings agents, models, projects, and tools into a connected workspace. Use supported local models, provider APIs, or subscription connections, with permissions and approvals for the work your agents perform.

[Get Girru](https://github.com/Dpro-at/Girru/releases) · [Explore its features](https://github.com/Dpro-at/Girru/blob/main/FEATURES.md) · [Read the contributor guide](https://github.com/Dpro-at/Girru/blob/main/CONTRIBUTING.md)

### Have an app or skill to share?

Start in **[girru-store](https://github.com/Dpro-at/girru-store)**:

- **Apps and extensions** add executable capabilities.
- **MCP listings** connect the catalogue to additional tools and servers.
- **Skills** provide reusable instructions and workflows.
- **Specialties** describe the jobs an agent can take on.

Follow the [Store contribution guide](https://github.com/Dpro-at/girru-store/blob/main/CONTRIBUTING.md). Shared workspace, memory, permissions, and desktop changes belong in the [Girru repository](https://github.com/Dpro-at/Girru). Tool access is configured separately from installing content.
